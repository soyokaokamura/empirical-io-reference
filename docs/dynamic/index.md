# Dynamic Parameter Estimation — 概要

エージェントが**将来の状態を考慮して意思決定**するモデルの推定手法群。
単一エージェント（Rust型）から複数エージェントの動的ゲーム（BBL型）まで。

## 手法一覧

| 手法 | エージェント | 計算コスト | 均衡概念 | 特徴 |
|------|------------|-----------|---------|------|
| [Rust NFXP](rust.md) | 単一 | 中 | 動的最適化 | Value Function Iterationを毎回解く |
| [Hotz-Miller CCP](hotz_miller.md) | 単一 | 低 | 動的最適化 | CCPを使って将来価値を近似 |
| [BBL](bbl.md) | 複数 | 高 | MPE | 均衡条件を不等式として使用 |
| [POB](pob.md) | 複数 | 中 | MPE | モーメント不等式 → 識別集合 |
| [AM NPL](npl.md) | 複数/単一 | 中 | MPE | CCPを反復更新して効率性向上 |

## 共通の構造

動的モデルの基本構造:

\[
V(x_t) = \max_{a_t} \left[ u(a_t, x_t; \theta) + \beta \int V(x_{t+1}) \, dP(x_{t+1}|x_t, a_t) \right]
\]

- **状態変数** \(x_t\): 現在の状況（設備の劣化度・競合企業のTFP等）
- **行動** \(a_t\): 離散的または連続的な意思決定
- **割引因子** \(\beta\): 将来の価値の割引（通常 0.9〜0.99）
- **推定対象** \(\theta\): 期間効用関数のパラメータ

## 単一エージェント vs 動的ゲーム

**単一エージェント（Rust, Hotz-Miller）**:
- 戦略的相互作用なし
- 企業の参入・退出・投資の決定を1社として分析
- 計算は比較的簡単

**動的ゲーム（BBL, POB, AM）**:
- 複数企業が互いの行動を予測して意思決定
- Markov Perfect Equilibrium (MPE) を均衡概念として使用
- **次元の呪い**と**複数均衡**が主な推定上の課題
