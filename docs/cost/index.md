# Cost Estimation — 概要

企業の**限界費用・費用構造**を推定する手法群。
費用を直接観察できないため、需要推定結果や投入データを使って間接的に推定する。

## アプローチの分類

| アプローチ | 方向 | データ | 代表手法 |
|-----------|------|--------|---------|
| **均衡条件からの逆算** | 需要推定 → 均衡FOC → mc | 市場価格・シェア | Markup / FOC-Based |
| **生産関数の推定** | 投入 → 産出 → TFP → mc | 工場・企業レベルパネル | OP / LP / ACF |
| **費用フロンティア** | 費用 → 効率性 | 費用・産出データ | Stochastic Frontier |

## 重要な注意点

- **行動仮定の感度**: Bertrand vs Cournot vs カルテルで推定されるmcが大きく変わる
- **需要推定誤差の伝播**: FOCベースの手法は第1段階（需要推定）の誤差を引き継ぐ
- **妥当性チェック**: 推定されたmcが負でないか、費用shifterと整合するか確認
