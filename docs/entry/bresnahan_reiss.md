# Bresnahan-Reiss (1991)

## 概要

市場への参入者数から、**参入の閾値条件**（何社参入すると利潤がゼロになるか）を推定。
企業の費用や需要パラメータを、参入データのみから識別する静的参入モデルの基礎。

---

## モデル設定

\(n\) 番目の企業が参入する条件:

\[
V_n(x, \xi) \geq 0
\]

- \(V_n\): \(n\) 社目の参入企業の期待利潤
- \(x\): 市場特性（人口・所得等）
- \(\xi \sim N(0,1)\): 観察不能な市場魅力度

均衡参入者数:

\[
N^* = n \iff V_n \geq 0 > V_{n+1}
\]

---

## 主要仮定

| 仮定 | 内容 |
|------|------|
| **対称企業** | 全企業が同質（異質性を導入すると識別困難） |
| **自由参入** | 均衡では利潤ゼロ（参入費用まで回収） |
| **市場均衡** | 観察された参入者数は均衡 |
| **Ordered Probit 構造** | \(\xi \sim N(0,1)\) |

---

## 推定手順

1. 利潤関数を特定: \(V_n = x\alpha_n - F_n + \epsilon\)
2. 参入者数の分布を **Ordered Probit** で推定
3. **Per-firm entry threshold** \(S_n^*\) を計算:
   - \(S_n^*\): \(n\) 社が黒字化するために必要な市場規模（人口等）
   - \(S_1^* < S_2^* < \cdots\)（競争激化で必要規模が増加）

## 識別されるもの

- 市場サイズが参入に与える効果
- **競争の激化が利潤に与える効果**: \(S_n^* / S_1^*\) の増加率を比較

---
