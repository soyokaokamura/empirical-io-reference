# Entry / Exit Models — 概要

市場への**参入・退出の決定**を構造的に推定する手法群。
企業の参入決定から、参入費用・競争効果・市場の魅力度をリカバリーする。

## 手法一覧

| 手法 | データ | 均衡 | 複数均衡 | 特徴 |
|------|-------|------|---------|------|
| [Bresnahan-Reiss](bresnahan_reiss.md) | 参入者数・市場特性 | 静的 | なし（対称仮定） | 競争効果の識別 |
| [Berry (1992)](berry.md) | 参入者数・企業特性 | 静的 | 順序付けで緩和 | 企業異質性の導入 |
| [Ciliberto-Tamer](ciliberto_tamer.md) | 参入ダミー・特性 | 静的 | あり（識別集合） | 複数均衡に明示対処 |
| [Ericson-Pakes](ericson_pakes.md) | パネルデータ | 動的 MPE | あり | 産業動態の分析 |

## 参入ゲームの複数均衡問題

参入ゲームでは**複数均衡**が問題になる:

- 例: 2企業の参入ゲームで「A参入・B非参入」と「A非参入・B参入」が両方均衡になりうる
- → データが均衡のどれに対応しているか不明
- **対処法**:
    1. 均衡選択ルールを仮定（恣意的だが点識別可能）
    2. Partial Identification（Ciliberto-Tamer）
    3. 対称企業仮定（Bresnahan-Reiss）で問題を回避
