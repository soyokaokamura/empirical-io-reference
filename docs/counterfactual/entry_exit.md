# Entry / Exit Counterfactual

## 概要

参入規制の撤廃・強化、または外生的な費用変化が**参入構造と価格**に与える影響を分析。

---

## 静的参入モデルでの Counterfactual（Bresnahan-Reiss型）

### 手順

1. 参入モデルを推定してパラメータ \(\hat{\theta}\) を取得
2. 反事実シナリオを設定（例: 参入費用を半減）
3. 新しい均衡参入者数 \(N^{*cf}\) を計算
4. 参入者数の変化から価格・消費者余剰を推定

### 反事実の例

| シナリオ | 変化させるもの | 分析内容 |
|---------|-------------|---------|
| 参入規制撤廃 | 参入費用 \(F \to F/2\) | 新たな参入者数・価格低下 |
| 市場規模拡大 | 人口 \(M \to 2M\) | 参入者数・競争強度の変化 |
| 競合企業退出 | \(N^{-i}\) の変化 | 残存企業の利潤・投資変化 |

---

## 動的参入モデルでの Counterfactual（Ericson-Pakes型）

### 手順

1. 動的モデルを推定 → 参入費用 \(\kappa\)・スクラップ価値 \(\phi\)・投資収益 \(\theta\) を取得
2. 政策変化を実装（例: 参入費用補助金 \(\kappa \to \kappa - s\)）
3. **Forward Simulation**: 新しい均衡経路を複数回シミュレート
4. 産業構造の時系列変化を分析

### 分析できること

- 企業数・集中度の長期的変化
- TFP 分布の変化（競争による淘汰効果）
- 消費者価格の長期トレンド

---

## 注意点

!!! warning "複数均衡問題"
    動的ゲームでは反事実均衡が一意に決まらない場合がある。
    均衡選択ルールを明示するか、複数の均衡でのシミュレーション結果を報告する。
